## 目标结构（按你的确认：既要多个 TimeMap，也要每个 TimeMap 多条轨迹）

- **一个 TimeMap = 一个环境资产集合**：`Map.jbl + 各类 IsoMap*.jbl + pathFinal*.jbl` 都在 `./map/<TimeMap>/`。
- **一个 TimeMap 下多个目标轨迹**：每条轨迹保存到 `./map/<TimeMap>/<slot>/`（slot 可以是时间戳或你给定的名称），目录内至少包含：
  - `PathE2Val_true.jbl`
  - `pathFinalE2ValIn.jbl`
  - （可选但建议一致）`IsoMapE2ValIn_i_tt.jbl`、预览 png、选点 json

## 具体改造方案（不改保存逻辑，只把输入变为 CLI + 新增批量入口）

### A. 将 3 个现有脚本 CLI 化

- `main/mainObtainMap.py`
  - 增加 `argparse`，把目前硬编码的 Map 参数暴露为命令行：
    - `--time-map`（默认仍是现在脚本里写死的值，或改为默认“当前时间戳”但不强制）
    - `--mapsize-x/--mapsize-y`、`--obs-mapsize-x`、`--obs-mapsize-y`
    - `--num-uav`、`--num-value`、`--sure`、`--r`、`--stepsize`
    - `--num-obs-nocircle`、`--R-min/--R-max`、`--num-steps`
    - `--resolution-map-pos-x/--resolution-map-pos-y`
    - `--n-topo`、`--n-blank`、`--safety`
  - 保持 `fast_save(Map, 'Map', TimeMap)` 与 `plt.savefig('./map/<TimeMap>/Map')` 不变。

- `main/mainObtainIsoMap0901.py`
  - 增加 argparse：
    - `--time-map`（必填或给默认）
    - `--v-e`、`--v-p`
    - `--draw/--no-draw`（对应 `WH_main_obtainMapP(..., draw=...)`）
  - 保持输出文件名与目录完全一致（仍写到 `./map/<TimeMap>/`）。

- `main/mainObtainPathETrue.py`
  - 已有 argparse，但需要补齐：
    - `--time-map`（替换硬编码 `TimeMap`）
    - `--save-slot`：如果指定则用 `./map/<TimeMap>/<save-slot>/`；不指定就保持现状用 `time_tag`。
    - `--evader-file` 或 `--evader`：支持从 json/npy/csv 读取 Evader（Nx3：[x,y,theta]）
    - `--value-id-list`：替换硬编码 `id_list = [3,2,1]`
    - `--stepsize`：允许覆盖 Map 中的 Stepsize（若你希望严格以 Map 为准，也可不提供这个覆盖项）
    - 保留 `--web-pick/--host/--port/--points-file` 现有网页选点机制与保存输出。

### B. 新增 3 个批量循环入口（都从“清单文件”驱动）

你选择了“从清单文件读取 TimeMap 列表与每个 TimeMap 的轨迹数量”，因此建议新增一个统一的清单格式（yaml 或 json），例如：

- `configs/batch_generate.yaml`（示例字段）：
  - `maps`: 每个条目包含 `time_map` 与 map 参数覆盖（可选）
  - `isomap`: 每个条目包含 `time_map` 与 `v_e/v_p/draw`
  - `profiles`: 每个条目包含 `time_map`、`count`、`save_slot_pattern`、以及 Evader/Value 的来源

然后新增 3 个脚本（放在 `main/` 下，避免改动库代码）：

1) `main/mainBatchObtainMaps.py`
   - 读取清单 → 对每个 `time_map` 运行一次“Map 生成”逻辑（直接复用 `intercept/Map/obtainMap.obtainMap`），并按原逻辑保存到 `./map/<TimeMap>/Map.jbl`。

2) `main/mainBatchObtainIsoMaps.py`
   - 读取清单 → 对每个 `time_map` 加载 `Map.jbl` → 复用 `WH_main_obtainMapP/Ref/Iso` → 保存到 `./map/<TimeMap>/...`。

3) `main/mainBatchObtainEvaderProfiles.py`
   - 读取清单 → 对每个 `time_map` 循环生成 `count` 条轨迹：
     - 每条轨迹写入 `./map/<TimeMap>/<slot>/...`（slot 按 pattern 生成，例如 `profile_000`、`profile_001` 或时间戳）
     - 轨迹生成方式优先复用 `mainObtainPathETrue.py` 的逻辑（包括 web-pick 或非交互模式）
   - **保证**每个 slot 目录至少有 `PathE2Val_true.jbl` 与 `pathFinalE2ValIn.jbl`，从而 `TODCMARLEnv` 可以自动发现并在 reset 时切换 profile。

## 关键约束与验证方式

- **不改变保存逻辑**：所有输出仍落在 `./map/<TimeMap>/...` 与 `./map/<TimeMap>/<slot>/...`，文件名不变。
- **与 `TODCMARLEnv` 对齐验证**：批量生成后，用 `TODCMARLEnv(config={'time_map': <TimeMap>, 'evader_profile_mode': 'cycle'})` 连续多次 reset，确认 `info['profile']` 会在多个 slot 间轮换。
